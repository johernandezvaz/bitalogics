# Política de Privacidad

**Última actualización:** Marzo de 2026

Esta Política de Privacidad describe cómo **Bitalogics** recopila, utiliza y protege su información personal cuando visita o interactúa con el sitio web https://silqapps.com.

Al utilizar este sitio web, usted acepta las prácticas descritas en esta política.

---

# 1. Quiénes somos

Bitalogics es una agencia digital independiente que ofrece servicios que incluyen:

- Diseño de logotipo
- Branding
- Diseño y desarrollo de sitios web
- Aplicaciones web
- Aplicaciones móviles
- Consultoría digital

Bitalogics es operada por su propietario en México.

Para cualquier consulta relacionada con la privacidad, puede contactar a:

**Correo electrónico:** bitalogics@gmail.com

---

# 2. Información que recopilamos

Bitalogics recopila únicamente la información necesaria para operar el sitio web y responder a las consultas de los usuarios.

Los tipos de información que podemos recopilar incluyen:

## Información que usted proporciona

Al completar un formulario de contacto o enviar una solicitud, podemos recopilar:

- Nombre
- Apellidos
- Correo electrónico
- Número de teléfono (opcional)
- Tipo de servicio solicitado
- Contenido del mensaje

Esta información la proporciona voluntariamente.

---

## Información recopilada automáticamente

Al visitar el sitio web, es posible que se recopile automáticamente cierta información, como:

- Tipo de navegador
- Tipo de dispositivo
- Páginas visitadas
- Tiempo de permanencia en las páginas
- Sitios web de referencia
- Región geográfica general

Estos datos se recopilan mediante tecnologías web estándar, como **cookies o herramientas de análisis**.

Esta información se utiliza únicamente para comprender el uso del sitio web y mejorar su rendimiento.

---

# 3. Cómo usamos su información

La información recopilada puede utilizarse para:

- Responder a las consultas enviadas a través del formulario de contacto
- Evaluar posibles solicitudes de proyectos
- Mejorar el rendimiento y la usabilidad del sitio web
- Analizar patrones generales de uso

Bitalogics **no vende, alquila ni intercambia información personal con terceros**.

---

# 4. Herramientas y calculadoras gratuitas

Bitalogics ofrece herramientas gratuitas como:

- **SilqScope**
- **SilqPlanner**

Estas herramientas pueden almacenar datos temporales en su navegador (por ejemplo, selecciones o preferencias) para proporcionar funcionalidad.

Bitalogics **no recopila ni almacena datos financieros ni datos personales sensibles** de estas herramientas.

Los datos utilizados en las herramientas se procesan local o temporalmente y no se utilizan para identificar a usuarios individuales.

---

# 5. Cookies

Este sitio web puede utilizar **cookies** o tecnologías similares para:

- garantizar el correcto funcionamiento del sitio web
- recordar las preferencias básicas del usuario
- analizar patrones de tráfico

Las cookies son pequeños archivos que se almacenan en su dispositivo.

Si lo prefiere, puede desactivar las cookies en la configuración de su navegador, aunque es posible que algunas partes del sitio web no funcionen correctamente.

---

# 6. Servicios de terceros

Bitalogics puede utilizar servicios de terceros para operar o mejorar el sitio web, incluyendo, entre otros:

- proveedores de alojamiento web
- servicios de análisis
- proveedores de API

Estos terceros pueden procesar datos técnicos limitados necesarios para el funcionamiento de sus servicios.

Bitalogics no controla cómo los proveedores externos gestionan sus propias prácticas de privacidad.

---

# 7. Seguridad de los datos

Bitalogics toma medidas razonables para proteger la información enviada a través del sitio web.

Sin embargo, ningún método de transmisión por internet o almacenamiento electrónico puede garantizar la completa seguridad.

Los usuarios deben evitar enviar información personal o financiera confidencial a través del sitio web.

---

# 8. Retención de datos

La información personal enviada a través de los formularios de contacto podrá conservarse durante el tiempo necesario para:

- Responder a la consulta
- Mantener la comunicación con respecto a una solicitud de proyecto
- Mantener registros internos de las comunicaciones

Si desea solicitar la eliminación de su información, puede contactarnos en cualquier momento.

---

# 9. Sus derechos

Dependiendo de su ubicación, podría tener derechos con respecto a sus datos personales, incluyendo:

- Solicitar acceso a sus datos
- Solicitar la corrección de información inexacta
- Solicitar la eliminación de sus datos personales

Para ejercer estos derechos, por favor, contacte con:

**bitalogics@gmail.com**

Bitalogics hará todos los esfuerzos razonables para responder a dichas solicitudes.

---

# 10. Privacidad infantil

Este sitio web y sus servicios no están destinados a menores de 13 años.

Bitalogics no recopila deliberadamente información personal de menores.

Si se identifican dichos datos, se eliminarán de inmediato.

---

Bitalogics podrá actualizar esta Política de Privacidad ocasionalmente.

Cuando se realicen actualizaciones, se revisará la fecha de **Última actualización** que aparece en la parte superior de esta página.

El uso continuado del sitio web después de las actualizaciones implica la aceptación de la política revisada.
